# 重返算力神殿：皮衣无双

第二版为三层高塔地牢突围：雨夜广场 → 二选一机房 → 顶层黄金圣殿。无需登录，全部画面和音效在浏览器本地生成。

## 开始游戏

- 开局选择 **休闲 / 标准 / 困难 / 噩梦**，默认标准；开战后不能改变难度，重新开局时可以重选。
- 从显卡飞镖、大铲子、CUDA 力场、脉冲炮、Qoder 小鸭中选一把起手；自动攻击。
- `WASD`、方向键或按住战场拖动移动，手机使用相同拖动手势。
- 满通灵能量按 `Space`，每次任选四位盟友之一，再确认释放；取消保留能量。
- `B` / `Tab` 打开武器匣，暂停并调整三把出战武器；其余武器保留在背包。`1 / 2 / 3` 切换经验培养重点。
- 选到斯安威斯坦后按 `Shift` 开启子弹时间；`Esc` 暂停。切换窗口也会自动暂停。

## 四档难度

| 难度 | 适合的体验 | 战斗时间上限 |
| --- | --- | --- |
| **休闲** | 敌人更温和，Boss 更容易击破，出招更从容，容错更高。 | 3 分 30 秒 |
| **标准** | 均衡的清怪与守关压力，推荐第一次体验完整三层高塔。 | 3 分 30 秒 |
| **困难** | Boss 更耐打，技能更紧凑、弹幕更快，需要留好通灵并及时走位。 | 4 分 30 秒 |
| **噩梦** | 更强的守关者与持续的攻击压力，每次失误都更疼。 | 5 分 30 秒 |

标准流程仍以约 3 分钟为目标。困难与噩梦给出更多战斗时间，让玩家应对更耐打的 Boss 和更密集的技能；选卡、选门和地图切换不消耗战斗时间。无尽模式没有时间上限。

## 地牢路线

每层清怪提高突破进度，进度满后守关 Boss 登场；时间自然推进也能触发守关。击破前两层 Boss 后选择海克斯，再走入地面传送门切换整张地图。

1. **1F 外围霓虹广场**：狗仔、键盘手与盾牌保安，闪光灯收缩包围网；守关者为直播装甲车。
2. **2F 机房分支**：固定机柜掩体、可攻击引爆的电池桶、预警后开启的激光门；守关者为绝对协议体。
   - 左门 **极寒超频机房**：液冷管道破裂，小怪踩池减速 80%；主角移速减 15%，全武器冷却缩减 45%。
   - 右门 **断电暗网走廊**：12 秒停电中暴击率翻倍；恢复供电时闪白清场并掉落稀有武器。
3. **3F 黄金圣殿**：牛市经验狂欢、第三次海克斯、恶意砸盘陨石雨，迎战两阶段算力收割机 MK-I。

武器最高 Lv.5，下一次强化觉醒超武；二层守关掉落超频升级核心。三槽超武成型后，继续升级仍会稳定增加火力。背包中的武器保留等级，可在下一次守关前调整出战组合。

三把出战武器全部觉醒后，每次经验溢出增加全武器基础伤害 **1**，无尽模式增加 **1.5**。已拥有的武器全部觉醒后，超频升级核心增加基础伤害 **3**，无尽模式增加 **4**；这些收益按固定数值累加。

## 守关 Boss 玩法

守关者登场后会较快开始出招。先观察红线、红圈和弹幕方向，再用通灵创造输出机会；武器成长和超武仍有收益，Boss 的耐打程度与出招压力随难度变化。

- **1F 直播装甲车**：车头红线预警后直线冲撞，急刹时释放旋转闪光弹幕。横向离开冲撞路线，等它刹车再靠近。
- **2F 绝对协议体**：律师函先飞出，再沿原路返回；电子栅栏预警 1.5 秒后开启，持续 5 秒。留意回程弹幕，并绕向机柜外侧通道。
- **3F 算力收割机 MK-I**：前半段有绕身董事护卫和螺旋弹幕。主席跌到半血时触发短暂转阶段防护，随后进入狂暴；看到 **危** 与全屏红线，就在 1.2 秒预警内进入安全缝隙。转阶段防护结束后再集中火力。

## 战报、分享与无尽

击败主席后可下载含难度、路线与楼层记录的战报 PNG，或复制 `#run=v4_…` 种子链接。新链接记录分享者的难度、起手武器和机房路线提示，玩家仍可自由选门；相同种子、难度、楼层、地图与决策可复现候选和掉落。兼容旧 `v2` / `v3` 链接，目标仅供本地挑战参考。

胜利后可带着全部超武背包、三槽构筑与海克斯进入 **4F AI 奇点核心**，继续挑战随机地图与强化词缀楼层，直到生命耗尽。

时停、黑闪和死亡滤镜对整帧合成一次；暂停、选卡与结算缓存静止战场，停止重复刷新界面。画布限制高分辨率开销，弹幕命中与机柜绕行也使用缓存。

## 本地开发

需要 Node.js **22.13.0 或更新版本**。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。静态发布可运行 `npm run build`，产物位于 `dist/`。

本次开发包含三层地图、进度守关、分支事件、环境机关、多 Boss、四档难度、地牢战报与无尽攀塔。**按用户要求，未运行测试或构建，玩法、难度与实际时长由用户自行验收。**
